# Self-Hosted Web Fonts

This directory contains self-hosted web fonts for Divemap:
- **DM Sans** (Variable, normal & italic, weights 100-1000): Designed by Colophon Foundry.
- **Outfit** (Variable, normal, weights 100-900): Designed by Rodrigo Fuenzalida.
