# Original Uncompressed Divemap Art Assets & Logos

This directory contains the original, full-resolution source image files for the Divemap project.

**Important:** Do NOT delete or overwrite the files in this directory.

- `arts/`: Original artwork assets (corals, fish, bubbles, shells).
- `logos/`: Original brand logo assets and backgrounds.

Production assets used in the application are optimized versions (modern WebP and compressed PNG) located in `frontend/public/arts/` and `frontend/public/`.
